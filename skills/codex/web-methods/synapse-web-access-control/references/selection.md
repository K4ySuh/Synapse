# Selection and handoff

Select this package for a specific actor/object, actor/function, or
actor/property comparison. Bring known actor roles, resource ownership,
expected policy, observed requests and responses, and saved evidence IDs.
Without a reliable comparison or policy basis, record the missing evidence.

The main web skill's existing authentication and access-control reference is
available at
`synapse://guidance/skills/synapse-web-pentesting/references/auth-and-access-control.md`.
For native skills installed beside the default profile, open
`synapse-web-pentesting/references/auth-and-access-control.md` under the same
skill root. The hosted catalog lists the URI directly; its relative Markdown
links do not resolve themselves through MCP.
Return to the main web method after recording the conclusion, contrary
evidence, and remaining question in canonical workspace state.
